

# Interactive Data Dashboard with R Shiny

## 📌 Overview
An interactive web-based analytics interface built with R Shiny, enabling dynamic data exploration through responsive charts and filterable tables. This personal project explores the intersection of statistical computing and interactive UI design.

## 🛠 Tech Stack
- **Language:** R
- **Libraries:** Shiny, ggplot2, dplyr, plotly

## 📊 Dataset
Dataset telah melalui proses *scrambling* dan anonimisasi untuk menjaga privasi, tanpa mengubah distribusi statistik utama yang relevan dengan pemodelan.

## 🚀 Methodology
1. Data acquisition and preprocessing using tidyverse
2. Exploratory Data Analysis (EDA) with ggplot2
3. Shiny reactive UI/UX design and optimization
4. Interactive filter and drill-down implementation

## 📈 Key Results & Metrics
- Interactive response time: < 200ms
- 5+ dynamic visualization types implemented
- Responsive across desktop and mobile breakpoints
