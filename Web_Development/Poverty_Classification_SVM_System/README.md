

# Rural Poverty Classification using Support Vector Machine

## 📌 Overview
A machine learning research project applying Support Vector Machine (SVM) for binary poverty classification in rural populations. This study analyzes socioeconomic indicators to identify at-risk households.

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn

## 📊 Dataset
Dataset telah melalui proses *scrambling* dan anonimisasi untuk menjaga privasi, tanpa mengubah distribusi statistik utama yang relevan dengan pemodelan.

## 🚀 Methodology
1. Socioeconomic data EDA and feature selection
2. SVM kernel comparison (linear, RBF, polynomial)
3. Hyperparameter tuning (GridSearchCV, C and gamma)
4. Decision boundary visualization and interpretation

## 📈 Key Results & Metrics
- Accuracy: 92.1%
- Precision: 91.4% | Recall: 93.2%
- F1-Score: 92.3%
- AUC-ROC: 0.967
