# SpecBudget - Interactive PC Build Planner & Budget Calculator

## Overview
A responsive client-side web application designed to help PC builders customize hardware components, calculate power consumption wattage, and manage total project budgets in real time.

## Key Features
- **Smart Component Configurator:** Step-by-step selection for CPU, GPU, Motherboard, RAM, Storage, and PSU.
- **Dynamic Wattage & Cost Calculation:** Real-time summary of estimated power requirements and pricing.
- **Responsive UI/UX:** Clean, modern, high-contrast dark theme optimized for desktop and mobile displays.

## Tech Stack
- **Frontend:** HTML5, CSS3 (Modern Flexbox/Grid), Vanilla JavaScript (ES6+)
- **Assets:** Custom SVG component icons
