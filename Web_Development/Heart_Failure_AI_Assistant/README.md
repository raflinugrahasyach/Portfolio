# Heart Failure Medical Chatbot (NLP-Based)

## 📌 Overview
An NLP research project developing a conversational interface for heart failure symptom triage. This personal experiment investigates intent classification and entity extraction in the Indonesian medical domain using pre-trained transformer models.

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** HuggingFace Transformers, NLTK, FastAPI/Streamlit

## 📊 Dataset
Dataset telah melalui proses *scrambling* dan anonimisasi untuk menjaga privasi, tanpa mengubah distribusi statistik utama yang relevan dengan pemodelan.

## 🚀 Methodology
1. Medical corpus collection and annotation
2. Intent classification model training (IndoBERT)
3. Entity extraction pipeline for symptom keywords
4. Dialogue flow and response generation design

## 📈 Key Results & Metrics
- Intent Classification Accuracy: 89.3%
- Response Relevance Score: 87.6%
- Entity Recall (symptom keywords): 91.2%
