

# Descriptive Statistics & Exploratory Data Analysis Tutorial

## 📌 Overview
A comprehensive EDA and descriptive statistics learning project that documents best practices in data profiling, distribution analysis, and visual storytelling. Created as a personal reference guide for analytical workflows.

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, SciPy

## 📊 Dataset
Dataset telah melalui proses *scrambling* dan anonimisasi untuk menjaga privasi, tanpa mengubah distribusi statistik utama yang relevan dengan pemodelan.

## 🚀 Methodology
1. Data profiling: shape, types, missing values
2. Univariate and bivariate analysis
3. Distribution visualization (histograms, boxplots, violins)
4. Correlation analysis and statistical testing

## 📈 Key Results & Metrics
- 10+ statistical tests demonstrated
- 15+ visualization types implemented
- Full reproducible pipeline from raw data to insights
