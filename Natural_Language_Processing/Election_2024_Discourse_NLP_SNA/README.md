# 2024 Indonesian Election NLP & Sentiment Analysis

## 📌 Overview
A comprehensive NLP research project analyzing Indonesian political discourse surrounding the 2024 General Election. This study combines sentiment analysis, topic modeling, and social network analysis to map online political opinion.

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** HuggingFace Transformers, NLTK, Gensim, NetworkX

## 📊 Dataset
Dataset telah melalui proses *scrambling* dan anonimisasi untuk menjaga privasi, tanpa mengubah distribusi statistik utama yang relevan dengan pemodelan.

## 🚀 Methodology
1. Social media corpus preprocessing (Indonesian tokenization)
2. Sentiment classification (IndoBERT fine-tuning)
3. LDA topic modeling for political themes
4. Social Network Analysis of discourse propagation

## 📈 Key Results & Metrics
- Sentiment Accuracy: 91.4%
- Topic Coherence (LDA): 0.54
- Network: 12 detected communities
