# Food Image Classification with CNN & Gradio Interface

## 📌 Overview
A deep learning research project for automated food category recognition using a fine-tuned CNN with Gradio-powered web interface. This project explores lightweight release of image classification models.

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** TensorFlow/Keras, Gradio, Pillow, NumPy

## 📊 Dataset
Dataset telah melalui proses *scrambling* dan anonimisasi untuk menjaga privasi, tanpa mengubah distribusi statistik utama yang relevan dengan pemodelan.

## 🚀 Methodology
1. Food image dataset augmentation and preprocessing
2. CNN architecture selection and fine-tuning
3. Gradio interface construction for real-time inference
4. Model export and release optimization

## 📈 Key Results & Metrics
- Classification Accuracy: 95.7%
- Inference Time: ~120ms per image
- Categories Supported: 15 food classes
