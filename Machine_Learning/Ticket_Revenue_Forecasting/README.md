# Ticket Revenue Time-Series Forecasting

## 📌 Overview
A time-series forecasting research project predicting ticket revenue using multiple forecasting models. This study compares classical statistical methods against modern ML approaches for financial projection.

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** Prophet, Statsmodels, Pandas, Matplotlib, Scikit-learn

## 📊 Dataset
Dataset telah melalui proses *scrambling* dan anonimisasi untuk menjaga privasi, tanpa mengubah distribusi statistik utama yang relevan dengan pemodelan.

## 🚀 Methodology
1. Time-series EDA (stationarity, seasonality, trend)
2. ARIMA/SARIMA baseline modeling
3. Facebook Prophet fine-tuning
4. LSTM sequence model training
5. Ensemble forecast combination

## 📈 Key Results & Metrics
- MAPE: 4.7% (Prophet)
- RMSE: 2,341 units (LSTM)
- Forecast Horizon: 90 days
