

# Predictive Regression with Random Forest Ensemble

## 📌 Overview
A machine learning research project applying Random Forest regression to predict continuous target variables. This study benchmarks RF against linear baselines and analyzes feature importance for domain-specific data.

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn

## 📊 Dataset
Dataset telah melalui proses *scrambling* dan anonimisasi untuk menjaga privasi, tanpa mengubah distribusi statistik utama yang relevan dengan pemodelan.

## 🚀 Methodology
1. Exploratory Data Analysis and correlation mapping
2. Feature engineering and selection (SHAP values)
3. Random Forest hyperparameter tuning (GridSearchCV)
4. Cross-validation and performance benchmarking

## 📈 Key Results & Metrics
- R² Score: 0.924
- RMSE: 12.47
- MAE: 9.83
- OOB Score: 0.918
