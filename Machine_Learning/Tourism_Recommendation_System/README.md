

# Tourism Destination Recommendation System

## 📌 Overview
A recommendation system research project that applies collaborative filtering and content-based approaches to suggest tourist destinations. The system explores hybrid recommendation strategies to maximize user preference matching.

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** Scikit-learn, Pandas, Surprise, Streamlit

## 📊 Dataset
Dataset telah melalui proses *scrambling* dan anonimisasi untuk menjaga privasi, tanpa mengubah distribusi statistik utama yang relevan dengan pemodelan.

## 🚀 Methodology
1. Web scraping and data collection pipeline
2. User-item interaction matrix construction
3. Collaborative filtering (SVD, KNN)
4. Content-based filtering (TF-IDF similarity)
5. Hybrid model evaluation with A/B testing

## 📈 Key Results & Metrics
- RMSE (SVD): 0.834
- Precision@10: 0.76
- Recall@10: 0.71
