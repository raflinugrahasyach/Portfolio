

# Hepatitis C Progression Prediction with Machine Learning

## 📌 Overview
A clinical machine learning research project predicting Hepatitis C progression stages from biochemical markers. This study evaluates multiple classification algorithms on medical data.

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn

## 📊 Dataset
Dataset telah melalui proses *scrambling* dan anonimisasi untuk menjaga privasi, tanpa mengubah distribusi statistik utama yang relevan dengan pemodelan.

## 🚀 Methodology
1. Medical dataset EDA and clinical feature analysis
2. Data preprocessing (imputation, normalization)
3. Multi-model comparison (Logistic Regression, SVM, RF, XGBoost)
4. ROC-AUC analysis and clinical threshold optimization

## 📈 Key Results & Metrics
- Best Model Accuracy: 93.7%
- AUC-ROC: 0.971
- Sensitivity: 94.1% | Specificity: 92.8%
