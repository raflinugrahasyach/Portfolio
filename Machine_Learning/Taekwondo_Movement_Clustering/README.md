# Taekwondo POOMSAE Movement Clustering Analysis

## 📌 Overview
An unsupervised machine learning research project analyzing Taekwondo POOMSAE movement patterns through clustering algorithms. This study identifies natural groupings in motion data for sports analytics applications.

## 🛠 Tech Stack
- **Language:** Python
- **Libraries:** Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn

## 📊 Dataset
Dataset telah melalui proses *scrambling* dan anonimisasi untuk menjaga privasi, tanpa mengubah distribusi statistik utama yang relevan dengan pemodelan.

## 🚀 Methodology
1. Motion feature extraction and normalization
2. Optimal cluster number selection (Elbow + Silhouette)
3. K-Means and Hierarchical clustering
4. Cluster profiling and sports interpretation

## 📈 Key Results & Metrics
- Optimal clusters (k): 5
- Silhouette Score: 0.68
- Davies-Bouldin Index: 0.41
